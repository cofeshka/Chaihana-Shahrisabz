# Чайхана «Шахрисабз» — сайт меню

Одностраничный сайт меню восточной кухни с корзиной и формой заказа на самовывоз.
Работает полностью на статике (HTML + CSS + JS) — можно разместить бесплатно на
GitHub Pages, Netlify, Vercel или любом хостинге.

## Структура

- `index.html` — страница: шапка, hero, меню блюд, корзина, форма заказа
- `styles.css` — все стили (включая адаптив и мобильное бургер-меню)
- `script.js` — корзина, фильтры меню, маска телефона, отправка заказа
- `logo.png` — логотип чайханы

## Запуск локально

Просто откройте `index.html` в браузере. Для полноценного тестирования можно
поднять локальный сервер:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `shahrisabz-menu`)
2. Загрузите файлы: `index.html`, `styles.css`, `script.js`, `logo.png`
3. Settings → Pages → Source: `main` branch, `/ (root)` → Save
4. Через пару минут сайт будет доступен по адресу
   `https://<username>.github.io/shahrisabz-menu/`

## Приём заказов (важно!)

Сейчас заявки **сохраняются только в браузере клиента** (localStorage, ключ
`shahrisabz_orders`) — при статическом размещении сами заявки никуда не
приходят. Перед запуском подключите реальную отправку: Telegram-бот,
Google Sheets (Apps Script) или Formspree — место для вставки помечено
комментарием в `script.js` (функция `saveOrderLocally`).
